# DQ with AI

Data quality checking application for large CSV datasets using local LLM (Ollama) and DuckDB.

## Rollback

The last known-good state is tagged `v0.1-stable`.

To restore it:

```bash
git checkout v0.1-stable
```

Or to restore and create a clean branch from it:

```bash
git checkout -b my-branch v0.1-stable
```
